Time-scale evidence: a [2014 community modding explanation on Greenheart's forum](https://forum.greenheartgames.com/t/any-idea-how-to-interpret-the-various-time-values-in-gdt/10379) describes four seconds per week and four weeks per month, with twelve months per year. This is historical first-hand community evidence, not a verified specification of every current release. Afterlight independently implements this functional clock; it does not import another game's code or scheduling data.

## Simulation conventions

The studio opens in August 1981. Each month has exactly four simulated weeks. Normal / fast / very fast speeds are 4, 1.5 and 0.5 seconds per week; +1 advances one week. Dialogs and milestones pause time. This calendar is a game abstraction, not a Gregorian day simulation.

The table lists the historical reference window used in the game, not a simultaneous worldwide release. All entries arrive in week one of the stated month. PC Compatible represents an evolving market category rather than a single product; its January 1984 entry is a modeled transition. Retirement windows and market shares are modeled gameplay values.

## Existing saves

Existing elapsed weeks, release timestamps, cash, staff, research and active projects remain unchanged. Those week values now display through the four-week historical calendar. Already owned licenses remain owned. A future-dated platform cannot be selected for a new game until its historical window; an existing project or release is retained. Old pending bulletins are retained. Announced-platform tracking is rebuilt once for the revised schedule. Previous completed campaign flags are retained.
